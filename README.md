## Project Name:
### 🍕 PizzaHub — Online Pizza Ordering Platform

## Project Description:
PizzaHub is a full-stack food ordering application that connects customers with pizza vendors through an intuitive, responsive, and user-friendly interface.
The client application provides a modern interface for browsing menus, authentication, ordering food, tracking order-related activities, managing profiles, and accessing vendor dashboard features.
It communicates with a separate Express.js backend API for authentication, database operations, order management, menu management, and payment processing.
